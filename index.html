How It Works

  • Rasberry pi

    Open the Rasberry Pi. Then enter the patient's name and surname into the system, then save the stethoscope you placed on the patient with the save button you see on the screen via the microphone inside the stethoscope.

  • Detection

    After you record the sound, select it from the files by pressing the detection button you see on the screen, and then the detection result will appear on the screen.

  • Traking

    Patient data will be sent to the voice recording, spectrogram and disease detection tracking system in folders created specifically for each patient and person via the Firebase cloud storage system.
